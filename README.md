# ExpotecnicaSys Academic Project for internal use

Web application developed using ASP.NET Core to manage and evaluate projects in an ExpoTecnica event. The system allows 
judges to score projects by category and view evaluation results in a simple and organized way. It was deployed on Azure 
with a cloud database, enabling access from any device.

## Features
- Manage evaluation categories
- Register and view project evaluations
- Score projects as a judge by selecting categories
- Display evaluation results in an organized interface
- Remote access through cloud deployment (Azure)

## Tecnologies
- C#
- ASP.NET Core
- Entity Framework Core
- SQL Server
- Azure (Cloud Deployment)
